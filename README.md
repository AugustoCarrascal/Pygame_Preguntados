🎮 Proyecto Pygame: Preguntados (Trivia Game)

Descripción

Juego de preguntas y respuestas estilo Preguntados desarrollado en Python utilizando la librería Pygame. El proyecto cuenta con una arquitectura modular y orientada a objetos que separa la lógica de eventos de la interfaz gráfica y el renderizado.

Características principales

Sistema de juego completo: Temporizadores por pregunta, gestión de vidas, rachas de aciertos y comodines por categoría.

Interfaz dinámica: Menús interactivos (Inicio, Configuración, Estadísticas y Pantalla de Juego) con detección de eventos e interacción vía cursor.

Persistencia de datos: Carga de preguntas dinámicas desde archivos CSV y almacenamiento de puntuaciones/estadísticas en formato JSON.

Audio y controles: Configuración e integración de efectos de sonido y música de fondo con control de volumen interactivo.

Stack tecnológico

Lenguaje: Python

Librería gráfica: Pygame

Formatos de datos: CSV, JSON
